# AGI Day 02 – Podsumowanie laboratoriów

Poniżej znajduje się zestawienie wszystkich laboratoriów wykonanych podczas drugiego dnia warsztatów AGI. Każdy notebook przedstawia inny aspekt tworzenia inteligentnych agentów z wykorzystaniem dużych modeli językowych (LLM), integracji z narzędziami oraz przetwarzania danych.

---

## 📄 Przegląd laboratoriów

### 🔹 [Lab 01 – Agent z interpreterem kodu i Anthropic](lab_1/README.md)
Tworzenie agenta opartego o model Claude (Anthropic), który może dynamicznie wykonywać kod Python w celu odpowiedzi na pytania użytkownika.

### 🔹 [Lab 02 – Agent z terminalem i modelem lokalnym (Gemma 3 4B via Ollama)](lab_2/README.md)
Agent z integracją terminala i lokalnie uruchamianym modelem za pomocą serwera Ollama. Wspiera lokalne wykonanie poleceń i modeli.

### 🔹 [Lab 03 – Agent LangChain + Cohere + wyszukiwarka Tavily](lab_3/README.md)
Agent ReAct z modelem Cohere Command R+ oraz narzędziem do wyszukiwania w Internecie. Potrafi analizować, planować i przeszukiwać sieć.

### 🔹 [Lab 04 – Agent GPT do pracy z DataFrame](lab_4/README.md)
Tworzenie agenta potrafiącego analizować dane z pandas DataFrame i rozmawiać o nich w języku naturalnym. Integracja z `create_pandas_dataframe_agent`.

### 🔹 [Lab 05 – Agent Cohere z dostępem do bazy SQL](lab_5/README.md)
Agent oparty o model Cohere, który automatycznie tłumaczy pytania na zapytania SQL i interpretuje odpowiedzi z bazy danych.

---

Każdy lab prezentuje inny typ integracji i zastosowania agentów AI w kontekście realnych danych i narzędzi pomocniczych.
