# AGI Day 04 – Zestaw Notebooków

Ten projekt zawiera zestaw notebooków ilustrujących zastosowania dużych modeli językowych (LLM) w różnych kontekstach, takich jak przeszukiwanie dokumentów, tworzenie agentów, przetwarzanie danych naukowych i wieloetapowe rozumowanie.

## Spis laboratoriów

### [Lab 01 – Query Router](lab_01/README.md)
System wykorzystujący dwa typy indeksów (streszczenie i wektorowy) oraz router LLM do kierowania zapytań użytkownika do odpowiedniego silnika.

### [Lab 02 – Serwis Samochodowy](lab_02/README.md)
Agent LLM wspierający diagnostykę, wyceny i planowanie serwisów samochodowych na podstawie danych JSON i bazy LanceDB.

### [Lab 03 – Pytania do Bazy](lab_03/README.md)
Porównanie klasycznego RAG i agentowego RAG w kontekście dokumentacji Hugging Face, z użyciem FAISS i sentence-transformers.

### [Lab 04 – Multihop](lab_04/README.md)
Agent ReAct odpowiadający na złożone pytania wieloetapowe, łącząc dane z bazy ChromaDB i zewnętrznych narzędzi (np. przelicznik walut).

### [Lab 05 – arXiv](lab_05/README.md)
Agent ReAct z możliwością pobierania, przeszukiwania i analizy publikacji naukowych z serwisu arXiv przy użyciu LlamaIndex i OpenAI.
