# AGI Day 1 Lab 1: Prosty Agent AI z użyciem Claude 3

## 📘 Opis
Ten notebook przedstawia prosty przykład, jak zbudować agenta AI wykorzystującego modele językowe firmy **Anthropic** (Claude 3). Jest to część ćwiczeń z zakresu AGI (Artificial General Intelligence), pokazująca, jak w praktyce używać modeli językowych do wykonywania zadań krok po kroku.

## 🧠 Cel
Celem notebooka jest:
- Pokazanie, jak skonfigurować środowisko do pracy z modelem Claude.
- Zaprezentowanie prostego agenta, który odbiera zadanie, planuje działania i je wykonuje.
- Umożliwienie eksperymentowania z podstawowym podejściem do agentów AI.
