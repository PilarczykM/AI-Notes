# 🧠 AGI Day 03 – Zestaw Projektów Laboratoryjnych

Zestaw laboratoriów opracowanych w ramach dnia 3 szkoleń AGI. Każde laboratorium prezentuje różne zastosowania agentów LLM w analizie danych, planowaniu, wyszukiwaniu informacji i automatyzacji działań.

---

### 🔗 [lab_01/README.md](lab_01/README.md)  
**LangGraph Text Analysis Workflow**  
Modularny przepływ analizy tekstu z LangGraph — klasyfikacja, ekstrakcja encji i podsumowanie treści, z użyciem OpenAI i lokalnego modelu Qwen3.

---

### 🔗 [lab_02/README.md](lab_02/README.md)  
**Asystent Planowania Podróży z LangGraph**  
Interaktywny agent do planowania jednodniowych wycieczek, prowadzący dialog z użytkownikiem i generujący spersonalizowane plany podróży z pomocą GPT-4.

---

### 🔗 [lab_03/README.md](lab_03/README.md)  
**Agregator Wiadomości z LangGraph**  
Agent wyszukujący i streszczający wiadomości z internetu przy użyciu NewsAPI, BeautifulSoup oraz modeli OpenAI. Szybki przegląd najważniejszych newsów.

---

### 🔗 [lab_04/README.md](lab_04/README.md)  
**Wikipedia Research Agent (LangChain + Milvus)**  
Agent analizujący pytania użytkownika, przeszukujący Wikipedię, zapisujący dane wektorowe w Milvus i generujący odpowiedzi przez LLM (DeepSeek + embedding).

---

### 🔗 [lab_05/README.md](lab_05/README.md)  
**Deep Research DIY Agent**  
Agent badawczy DIY: samodzielnie formułuje pytania, przeszukuje internet (Tavily), analizuje wyniki i przetwarza je przy pomocy modelu GPT-4o-mini (LiteLLM).

---

### 🔗 [lab_06/README.md](lab_06/README.md)  
**Browser Automation Agent (Playwright + Together AI)**  
Agent automatyzujący przeglądarkę: analizuje stronę (screenshot + accessibility tree) i wykonuje działania na podstawie modelu Llama 4 Scout 17B z Together AI.
