# AGI Day 1 Lab 2: Agent AI z dostępem do narzędzi OpenAI i Google

## 📘 Opis
Ten notebook demonstruje stworzenie prostego agenta AI, który potrafi korzystać z zewnętrznych narzędzi takich jak OpenAI GPT-4 oraz API Google. Agent jest w stanie analizować, przetwarzać i wykonywać polecenia użytkownika, integrując się z nowoczesnymi usługami API.

## 🧠 Cel
Celem notebooka jest:
- Pokazanie integracji modeli językowych z narzędziami zewnętrznymi (OpenAI, Google API).
- Budowa agenta wykonującego zadania z użyciem rozszerzonych możliwości modeli językowych.
- Nauka planowania i realizacji działań z pomocą API.
