# AGI Day 1 Lab 3: Agent AI z wykorzystaniem modelu LLaMA 3 lokalnie przez Ollama

## 📘 Opis
Notebook demonstruje, jak skonfigurować środowisko i uruchomić agenta AI lokalnie przy użyciu narzędzia **Ollama** oraz modelu **LLaMA 3.1**. Pokazuje lokalne podejście do uruchamiania i sterowania dużymi modelami językowymi bez konieczności korzystania z chmury.

## 🧠 Cel
Celem notebooka jest:
- Pobrać i uruchomić model LLaMA 3.1 lokalnie za pomocą Ollama.
- Zaprezentować podstawy interakcji z lokalnym modelem językowym przez API.
- Pokazać, jak budować prostego agenta AI bez potrzeby zewnętrznego dostępu do chmury.
